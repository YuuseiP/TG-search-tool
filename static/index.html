Clash 代理

开始索引

  1. 在 my.telegram.org 创建应用，获得 API ID 与 API Hash。
  2. 确认 Clash 已启动；默认使用 SOCKS5 127.0.0.1:7890。
  3. 填写手机号并完成验证码登录。
  4. 在频道管理中勾选频道，然后同步。
